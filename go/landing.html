The 5 beats

What makes it convert attention into retention

01 · SINGLE BINARY

One command install

curl | sh. No Docker, no Node, no Python. Go binary, ~15 MB, statically linked. Cross-compiled for Linux/macOS/ARM64.

02 · <60 SECONDS

First value fast

loomwork init → ask → package → run. Point it at a folder, it indexes and answers immediately via local Ollama.

03 · LOCAL-FIRST

No cloud by default

Ollama on localhost. Memory in SQLite, encrypted at rest. No telemetry, no phone-home. Cloud is opt-in per command.

04 · PORTABLE .aci

Signed, verified, cross-device

Ed25519 signature + SLSA attestation + SBOM + property tests, automatic on every package. Same .aci runs anywhere.

05 · TYPED MEMORY

Follows the user, not the app

5 record kinds (preference, episode, artifact, belief, failure). Provenance, consent, retention. Revocation cascades to derivatives.

06 · ZERO CONFIG

No config nightmare

loomwork doctor checks every common failure mode and tells you what to do. No YAML, no env files, no debug rabbit holes.

The positioning

Not "the full OS on day one."

It's Pocketbase for agents — the .aci that makes agents portable.

Single-binary + immediate value is what converts attention into retention. The broader platform (mesh, Mission Control, formal verification) grows once the unit of packaging is adopted.

# 1. Install (one command) $ curl -fsSL https://raw.githubusercontent.com/arunsoman/loomwork/main/go/install.sh | sh # 2. Make sure Ollama is running $ ollama pull llama3.2 # 3. Check your setup $ loomwork doctor ✓ ollama reachable, 3 models installed ✓ memory 0 records, 0 embeddings ✓ workspace writable ✓ spec loomwork 0.1.0, spec aci.loomwork.dev/v0.1 # Then: $ loomwork init my-agent && cd my-agent $ loomwork ask "what does this folder contain?" --folder . $ loomwork package --out my-agent.aci $ loomwork run my-agent.aci
